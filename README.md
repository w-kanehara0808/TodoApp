# TodoApp

コンソールベースのタスク管理アプリケーションです。

## 概要

タスクの追加・完了・編集・一覧表示ができるシンプルなToDoリストアプリです。
CSVファイルへの保存・読み込みに対応しており、アプリを再起動してもデータが保持されます。

## 機能

- タスクの追加（タイトル・期限を設定）
- 未完了タスク一覧の表示（期限切れは自動判定）
- タスクの完了化
- タスクの編集（タイトル・期限の変更）
- 完了済みタスク一覧の表示
- CSVファイルへの保存・読み込み

## 使用技術

- Java 21
- Stream API / ラムダ式
- NIO.2（ファイルI/O）
- Git / GitHub

## 実行方法

1. Eclipseでプロジェクトをインポート
2. `Main.java` を実行

## 工夫した点

- コレクション操作をStream APIでリファクタリングし、可読性を向上
- 例外処理を実装し、不正な入力があっても再入力できる仕様に
- CSVファイルでのデータ永続化に対応
